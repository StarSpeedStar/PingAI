🌟 Ping AI Companion
Ping AI Companion is a sleek, lightning-fast, and user-friendly AI chat application built with Streamlit and powered by the Groq API. Designed for effortless daily productivity and deep analysis, Ping combines smart intent routing with a clean, modern interface to deliver precise results instantly.

✨ Key Features
🧠 Dynamic Model Selector: Seamlessly switch between top-tier AI models directly from the sidebar to match your exact performance and reasoning needs.

📂 Document Vault: Easily attach and analyze text files, Python scripts, CSVs, JSON, and markdown documents of any size with instant context merging.

⚡ Smart Intent Routing: Automatically evaluates incoming prompts to balance microsecond-fast responses for casual queries with deep structured thinking for complex coding and math problems.

🎨 Clean & Accessible UI: Features a modern, minimal aesthetic with high-contrast text visibility for both typing inputs and assistant responses.

🧹 Robust Session Controls: Manage your conversation flow effortlessly with quick chat history purging and real-time status indicators.
